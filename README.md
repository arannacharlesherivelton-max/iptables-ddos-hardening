# Linux Firewall & DDoS Hardening
Conjunto de regras avançadas de Iptables e otimizações de kernel (Sysctl) para blindagem de servidores Linux contra ataques de negação de serviço.

## Principais Proteções
- Bloqueio de pacotes inválidos e fragmentados.
- Mitigação de SYN Flood e controle de conexões simultâneas.
- Limitação de taxa de pacotes UDP para servidores de jogos.
- Ativação de SYN Cookies na pilha TCP/IP do kernel.
